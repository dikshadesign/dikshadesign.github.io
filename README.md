# Diksha — UI/UX & Industrial Design Portfolio

A scalable, multi-page portfolio built with HTML, CSS, and vanilla JS.

## Architecture & Design Library
This project uses a custom design token system located in `design-library/`.
- `tokens.css` - Single source of truth for colors, typography, spacing, etc.
- `typography.css` - Font sizes, weights, line heights.
- `components.css` - Reusable UI elements (buttons, cards, nav).
- `animations.css` - Keyframes and scroll-reveal utility classes.
- `utilities.css` - Layout and layout-specific helpers.

## Setup
1. Clone the repository.
2. Open `index.html` in your browser. No build tools required!

## Deployment
This repository is automatically deployed via GitHub Pages from the `main` branch.
