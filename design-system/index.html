Architecture / 01

1200px Max-Width Layout System

All portfolio pages are constrained to a disciplined 1200px bounding container (`--container-max: 1200px`), preventing excessive horizontal span while preserving comfortable typographic measure.

1200px Optical Container: width: min(1200px, calc(100vw - (var(--container-padding) * 2))) with fluid padding scales (clamp 18px to 48px). All grids, sections, and case study media align to this boundary.

Philosophy / 02

Geometric Radius Philosophy

Strict zero-radius rule across all structural elements paired with pill-shaped interactive controls.

Rule 1: Strict 0px Corners

Cards, Tiles, Images & Frames

All content containers have sharp, brutalist/modern 0px radiuses (`--radius-none: 0px`). No rounded corners on media or structural boxes.

0px Sharp Frame
Rule 2: Pill-Shaped Controls

Buttons, Badges & Status Pills

Interactive touchpoints utilize organic, continuous pill curves (`--radius-pill: 9999px`) for immediate affordance.
