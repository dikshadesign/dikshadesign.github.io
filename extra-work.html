Extra 01 · Physical Computing · 2026

Physical Control Console & Rotary Input Rig

A bespoke shop-floor tactile control console built to replace delicate touchscreens in oily manufacturing environments. Integrates stepped rotary encoders for instant exposure adjustments, toggle switches for camera triggers, and an emergency hardware interrupt button with sub-millisecond response.

Key Specifications & Build
  • Hardware Interface: Arduino Pro Micro configured as custom USB HID game controller / serial bridge.
  • Tactile Affordance: Knurled 25mm aluminum dials with 24-step detents for blind adjustment while wearing safety gloves.
  • Casing Fabrication: Laser-cut 5mm matte black acrylic chassis with countersunk hex fasteners.
Physical Computing Arduino / HID Rotary Encoders Shop-Floor Ergonomics Hardware Prototyping

Extra 02 · Web Tool & Vibe Coding · 2025

Real-Time Machine Vision Annotation Canvas

A lightweight, zero-dependency browser tool vibe-coded over a weekend for plant quality inspectors. Enables technicians to stream high-resolution 60 FPS optical camera frames, drag tight defect bounding boxes, tag anomalies, and push labeled training data directly into Nordic OS without software bloat.

Key Specifications & Build
  • Zero Latency: HTML5 Canvas 2D context optimized with requestAnimationFrame for 60fps rendering at 4K resolution.
  • Keyboard Workflow: Full single-hand keyboard shortcuts (Space to freeze, numbers 1-9 to tag defect classifications).
  • Direct Integration: Outputs standardized JSON coordinate matrices directly consumable by Python PyTorch models.
Vibe Coding HTML5 Canvas Machine Vision UI 60 FPS Inspection Vanilla JavaScript
STUDY-03 // NID WORKSHOP
📷 Image Slot: Edit assets/projects/extra/extra-03-ergonomics.svg or link workshop photos. Click to view full-screen.
Extra 03 · Industrial Design & Workshop · 2024

Handheld Scanner Grip & Reach Study

An anthropometric physical exploration designed to eliminate wrist fatigue during repetitive 8-hour scanning shifts. Tested multiple iterations—starting from hand-shaped high-density polyurethane styling foam, progressing to weighted FDM 3D prints, and finalizing with a dual-shot SLA resin body with knurled TPU overmold.

Key Specifications & Build
  • Anthropometrics: Accommodates 5th percentile female to 95th percentile male Indian hand dimensions.
  • Center of Gravity: Internal ballast cavities arranged to place the CG directly through the palm line, reducing muscle load.
  • Materials: Tough 2000 Resin with Shore 65A TPU grip inserts for drop and oil resistance.
NID MP Workshop Anthropometry Foam Prototyping 3D Printing (FDM & SLA) CMF Exploration

Extra 04 · IoT Interface & Telemetry · 2025

Industrial Sensor Telemetry Mini-Dashboard

A high-density oscilloscope and sensor monitor built for hardware technicians calibrating gantry rigs. Streams optical housing temperatures, 3-axis vibration levels, and strobe lux intensity over high-frequency WebSockets with real-time Fast Fourier Transform (FFT) harmonics visualizer.

Key Specifications & Build
  • High Sampling Rate: Ingests 1,000 samples per second with zero UI stutter via Web Workers.
  • Shop-Floor High Contrast: Dark-mode palette designed for dim optical chambers with emergency yellow and red threshold indicators.
  • Sensor Telemetry: Tested with ADXL345 digital accelerometers and TSL2591 optical lux sensors.
IoT Interface WebSocket Stream Telemetry Oscillation Hardware Sensor Hooks Dark-Mode Systems

Extra 05 · Spatial Design & Modular Hardware · 2024

Modular Exhibition Display & Pop-up Kiosk

A modular architectural demonstration booth designed for rapid deployment at industrial technology expos. Built using standard 40x40 anodized aluminum extrusions, tool-free quick-lock cam fasteners, and recycled PET acoustic felt baffles that absorb convention hall chatter.

Key Specifications & Build
  • Tool-Free Setup: Engineered for rapid 1-person assembly in under 20 minutes without specialized tools.
  • Flat-Pack Logistics: Packs into a single airline-compliant flight case (1200 x 450 x 300 mm, 32 kg total).
  • Integrated Tech: Concealed internal cable routing for interactive tablet kiosk and downlight LED illumination.
Spatial Design Aluminum Extrusion Acoustic Baffles Flat-Pack DFM Exhibition Architecture
