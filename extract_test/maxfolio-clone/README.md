# Diksha Maxfolio — React/Vite

A high-polish portfolio implementation inspired by the visual language of TD_Maxfolio: oversized editorial typography, restrained grid, project-first presentation, light/dark mode, scroll reveals and hover motion.

## Run
```bash
npm install
npm run dev
```
Then open the local URL shown by Vite.

## Customize
Edit `src/main.jsx` to replace project titles, descriptions, links, email and experience. Replace the generated abstract project visuals in `ProjectCard` with `<img>` or `<video>` assets when your final renders are ready.

## Build
```bash
npm run build
```
